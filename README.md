## clone repo
```bash
git clone -b cloudflare https://github.com/Syuhadak27/spreadsheet-read-bot-telegram.git
```

## Requirements
Rename <code>config-sampel.js</code>  ke <code>config.js</code>

•• <code>TOKEN</code> : token bot dari BotFather

•• <code>LOG_CHANNEL_ID</code> : id channel di awali <code>-100xxxxxxx</code>

•• <code>GOOGLE_API_KEY</code> : di peroleh dari google cloud console, aktifkan <code>google sheet API</code> credentials - API KEY

•• <code>WEBHOOK_URL</code> : url yg diperoleh dari hasil deploy di <code> Cloidflare</code>

•• <code>CHANNEL_USERNAME</code> : username channel publik, channel <code>wajib publik</code>

•• <code>SPREADSHEET_ID</code> : id spreadsheet
